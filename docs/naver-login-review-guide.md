## 2. 테스트 시나리오

### 시나리오 1: 신규 회원 가입
1. https://naraddon.com/auth/login 접속
2. "네이버 로그인" 버튼 클릭
3. 네이버 로그인 페이지로 리다이렉트
4. 네이버 계정으로 로그인
5. 동의 항목 확인 및 동의
6. 자동으로 회원가입 완료
7. /mypage로 리다이렉트

### 시나리오 2: 기존 회원 로그인
1. https://naraddon.com/auth/login 접속
2. "네이버 로그인" 버튼 클릭
3. 네이버 계정으로 로그인
4. 바로 /mypage로 리다이렉트

### 시나리오 3: 로그아웃
1. 마이페이지에서 로그아웃 버튼 클릭
2. 세션 종료
3. 로그인 페이지로 리다이렉트

## 3. 검수용 스크린샷 준비

### 필요한 스크린샷
1. **로그인 페이지**
   - URL: https://naraddon.com/auth/login
   - 네이버 로그인 버튼이 잘 보이도록

2. **네이버 동의 화면**
   - 필수 동의 항목 표시
   - 회원이름, 이메일, 휴대폰번호

3. **로그인 성공 후 마이페이지**
   - URL: https://naraddon.com/mypage
   - 사용자 정보 표시 화면

4. **프로필 정보**
   - 네이버에서 받아온 정보 표시
   - 추가 정보 입력 없이 자동 가입됨을 보여줌

## 4. 검수 신청서 작성 예시

### 서비스 소개
```
나라똔은 중소기업과 소상공인을 위한 정책 정보 플랫폼입니다.
정부 지원 정책, 전문가 상담, 비즈니스 인사이트를 제공합니다.
```

### 네이버 로그인 사용 목적
```
1. 간편한 회원가입 및 로그인 제공
2. 사용자 인증 간소화
3. 추가 정보 입력 없는 빠른 가입
4. 안전한 사용자 정보 관리
```

### 개인정보 처리
```
- 수집 항목: 이름, 이메일, 휴대폰번호
- 수집 목적: 서비스 제공, 회원 관리, 고객 상담
- 보유 기간: 회원 탈퇴 시까지
- 파기 방법: 복구 불가능한 방법으로 완전 삭제
```

## 5. 검수 신청 절차

1. **네이버 개발자 센터 접속**
   - https://developers.naver.com
   - 애플리케이션 관리 → 나라똔 홈페이지 선택

2. **검수 요청**
   - "네이버 로그인" 탭
   - "검수 요청" 버튼 클릭

3. **검수 정보 입력**
   - 서비스 URL: https://naraddon.com
   - 로그인 URL: https://naraddon.com/auth/login
   - 테스트 계정: (필요시 제공)

4. **증빙 자료 업로드**
   - 스크린샷 첨부
   - 서비스 소개서
   - 개인정보 처리방침 링크

## 6. 검수 통과 팁

### ✨ 중요 포인트
1. **ID/PW 입력 없음**: 네이버 정보로 자동 가입
2. **필수 정보만 수집**: 불필요한 추가 정보 요구 없음
3. **브랜드 가이드 준수**: 네이버 로고와 색상 정확히 사용
4. **안정적인 서비스**: 에러 없이 매끄러운 로그인 플로우

### ⚠️ 주의사항
1. 네이버 로그인 후 추가 정보 입력 화면 없어야 함
2. 회원가입과 로그인이 하나의 플로우로 처리
3. 로그아웃 기능 필수 구현
4. 개인정보 처리방침 명시
